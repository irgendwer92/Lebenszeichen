Set up this device

With an access token for your relay you can invite people yourself. Without one you can only accept invitations with a voucher.

You need neither a relay address nor an access token. The mailbox comes with the voucher of the invitation.

The setup code is shown to you by someone who runs a relay or has an account there. It contains the relay address and the access token.

You already have a device and are setting this one up as another. The relay must also know your existing device.

Set up as another device

Scan the code with an existing device (Devices → Add device) or enter it there.
