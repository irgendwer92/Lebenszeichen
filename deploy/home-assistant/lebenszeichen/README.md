# Lebenszeichen for Home Assistant

Runs `lz-server` next to Home Assistant. It answers for you with a reported
state such as "asleep" when you can't, and lets automations set that state.
Setup and settings are on a page in the sidebar.

See [DOCS.md](DOCS.md) for installation and use, and
`docs/local-interface.md` in the repository for the interface.
